The historical presence index is associated with official bunker sales, meaning marine-fuel sales. The correlation is 0.519 for year-over-year log changes (34 pairs) and 0.180 for adjacent-month log changes (52 pairs).

The comparisons use different eligible samples. The map shows separate monthly composites, not the individual overpasses used to construct that index. Bright returns are vessel candidates; their detection accuracy has not been established.

Adding backscatter change

A retrospective comparison on nine inspected test months reduced RMSE from 333.98 to 296.24 thousand tonnes when image change was added to the presence index.

The paired uncertainty interval is [−68.6, +23.2] thousand tonnes, including no improvement. Source-product lineage remains incomplete. This is a feature for further testing, not an established forecasting advantage.

Reading the map

The slider covers September 2025–August 2026. Each dot is a candidate return in a monthly radar composite. These are historical images, not live vessel positions. The rectangles are project-defined analysis areas, not official port boundaries.

AIS ship-position reports provide a separate comparison. Seven matched daily totals were insufficient to establish detection accuracy. Annual VIIRS night lights are contextual data, not inputs to the monthly estimation model.
